# Python CLI Tool for analyzing DNA Content 
## How it works :
- GC content Analyzer :
  GC content Calculation -
  This python script reads a FASTA file and calculates GC content.
  
  Input: gene.fna (FASTA sequence file)
  Output: GC percentage of the sequence.
